# YiHangPavilion

一个为个人使用设计的浏览器起始页。

整合常用网站、聚合搜索、时间与日常信息，让浏览器首页保持简单、安静且高效。

[在线访问](https://navigation.beyondxin.com/)

## 技术栈

Nuxt 4 · Vue 3 · TypeScript · Pinia · Naive UI · UnoCSS

## 开发

```bash
pnpm install
pnpm dev
```

静态构建：

```bash
pnpm build
```

生成内容位于 `.output/public`，可直接部署到静态服务器或 CDN。
